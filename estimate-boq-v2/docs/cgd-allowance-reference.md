# ส่วน A — Phase 1 โครงสร้าง (wire เข้า `gridDerive.ts`)

## A1. งานขุดดินฐานราก + ถมคืน — **เผื่อ 30% (×1.30)** · ข้อ 1

> **นี่คือตัวเคลียร์ rule 14:** ใช้ "ปริมาตรขุดสุทธิ × 1.30" สำหรับราคากลางราชการ
> วิธี +0.50ม.ข้างละ (convention เดิมหน้างาน) ถูก supersede สำหรับงานราคากลาง

- ปริมาตรขุดสุทธิ = พื้นที่ฐาน × ความลึกขุด (ยังต้องนิยาม "ความลึกขุด" ในโมเดล → ดู §E)
- ปริมาตรขุดคิดราคากลาง = ปริมาตรขุดสุทธิ × 1.30
- ดินถมกลับ = ปริมาตรขุด − ปริมาตรฐาน − ทรายรอง − lean − ตอม่อ (สูตรเดิม rule 14 คงไว้)

# ส่วน E — Spec สำหรับ constants module (`gridDerive` integration)

โครงที่จะเสนอ (รอ recon T1–T5 ก่อนเคาะ path จริง):


**กฎการ wire:**
