# Baseline ปร.4/5/6 — สพฐ. อาคารห้องสมุด (Attach_BOQ_1.xls) + สเปค template export

> เอกสารราชการจริงรูปแบบ Excel — ใช้เป็น (1) regression baseline ชั้น compute
> และ (2) **ต้นแบบโครงสร้างชั้น export Excel** ของระบบ
> สถานะ: เลขทุกชุดผ่าน test แล้ว (รอบ 22)

## 1) ที่มา
- ประมาณราคาอาคารห้องสมุด สพฐ. — ไฟล์ Attach_BOQ_1.xls (7 sheets)
- Sheets: ปร.4(ก) · ปร.4(ข) · ปร.4(พ) · ปร.5 · ปร.6 · Factor F
- ใช้เป็นต้นแบบ layout คอลัมน์/สูตร/การยกยอด ของ export โดยตรง

→ ระบบรองรับด้วย `approxStep` config (default 1000 · ตั้ง 100 ได้)

## 3) โครง section มาตรฐาน (กลุ่มงานที่ 1 — งานโครงสร้าง)
1.1 งานดิน หิน ทราย และฐานราก
1.2 งานตอกเสาเข็ม
1.3 งานแบบหล่อคอนกรีต
1.4 งานคอนกรีตโครงสร้าง
1.5 งานเหล็กเสริมคอนกรีต
1.6 งานพื้นสำเร็จรูป
1.7 งานโครงหลังคาเหล็ก

→ mapping จาก BOQ category: หมวด "ฐานราก" แตกเข้า 1.1 (ดิน/ทราย/lean) + 1.3 (ไม้แบบ)
+ 1.4 (คอนกรีต) + 1.5 (เหล็ก) — section แบ่งตาม**ชนิดงาน** ไม่ใช่ชิ้นส่วน

## 5) รูปแบบแถวเฉพาะของ สพฐ. (ต้อง map ตอน export)
- "ขุดดินฐานรากและถมคืน (แรงคน)" = แถวเดียว labor-only (รวมขุด+ถมคืน)
- "ดินถมปรับระดับ" มีค่าวัสดุ (ซื้อดิน) = key `earth:fill_grading`
- ไม้แบบ: ปริมาณหน่วย **ลบ.ฟ.** แต่ค่าแรงไม้แบบหน่วย **ตร.ม.** (dual-column qty ต่างกัน)
- เหล็กเสริม: แสดงหน่วย**ตัน 3 ตำแหน่ง** ที่ชั้น export (compute เก็บ กก. เสมอ)
- ตะแกรง wire mesh แผ่น มอก.737-2549 = net ไม่เผื่อ · ไม่เข้าฐาน Σ เหล็ก (ลวดผูก/ค่าแรง)

## 6) กติกา ปร.5(ข) — ครุภัณฑ์
- ครุภัณฑ์**จัดซื้อ** → ปร.5(ข): ×1.07 (VAT) **ไม่ผ่าน Factor F**
- ครุภัณฑ์**สั่งทำ** → อยู่กลุ่มงานส่วนที่ 1 โดน Factor F ปกติ
- เส้นแบ่งจัดซื้อ/สั่งทำ ยังไม่ implement — งานค้าง

## 7) สเปคชั้น export ที่ต้องทำตาม template นี้
- layout คอลัมน์ ปร.4 dual-column (วัสดุ|ค่าแรง) ตาม Por4Row
- "รวมยอดยกไป" ท้ายหน้า + เลขหน้า = ความรับผิดชอบของชั้น export เท่านั้น
- ปร.5: แสดง F + ยอดสุทธิ + จำนวนเงินตัวอักษรไทย
- ปร.6: Σ ยอดสุทธิรายส่วน + ตัวอักษร
