## 3. กฎการจัดกลุ่ม / รวมรายการ ★ (หัวใจ — ตรงกับ merge ที่กำลังทำใน buildBOQ)

1. **คอนกรีตแยกตามเกรด**
   - คอนกรีตหยาบ 1:3:5 (lean) = **บรรทัดแยก** ของตัวเอง
   - คอนกรีตโครงสร้าง "ค.2" = **บรรทัดเดียว** — ฐานราก + ตอม่อ รวมอยู่ในนั้น (= design B ของเรา)
2. **เหล็กเสริม = 1 บรรทัดต่อ "ขนาดเส้นผ่านศูนย์กลาง"** (Dia 25/20/16/12/9/6 มม.)
   - รวมเหล็กขนาดเดียวกันจากทุก element (ตะแกรงฐาน + ยืนตอม่อ + ปลอก ฯลฯ) เข้าบรรทัดเดียว
   - คนละขนาด = คนละบรรทัด (คนละราคา/หน่วย)
3. **วัสดุ/งานชนิดเดียวกัน รวมเป็นบรรทัดเดียว**: ไม้แบบ · ค่าแรงไม้แบบ · ไม้เคร่า · ตะปู · เสาค้ำไม้แบบ · ลวดผูกเหล็ก · ทราย · ขุดดิน · ถมดิน
4. **รวม "ภายใน section"** — เหล็ก/คอนกรีตใน 1.1 (ฐานราก) แยกจาก 1.2 (เสา-คาน-พื้น) · ไม่รวมข้าม section
5. **Factor F คิดครั้งเดียวที่ยอดรวมสุดท้าย** (ที่นี่ 1.26280) — ห้าม bake ลงรายการย่อย
6. คอลัมน์ ปร.4: ลำดับ · รายการ · จำนวน · หน่วย · [ราคาวัสดุ: /หน่วย, รวม] · [ค่าแรง: /หน่วย, รวม]
