# Baseline ปร.4/5/6 — สพฐ. แบบ 212 ล./57-ก (ปรับราคา 14 ก.ค. 2564)

> เอกสารราชการจริง ใช้เป็น regression baseline ของชั้น compute ปร.4/5/6
> สถานะ: เลขทุกชุดผ่าน test แล้ว (รอบ 22) — ห้ามแก้เลขโดยไม่มีเอกสารราชการหักล้าง

## 1) ที่มา
- แบบมาตรฐาน สพฐ. อาคารเรียน 212 ล./57-ก
- ประมาณราคาปรับปรุง 14 ก.ค. 2564 (Factor F ใช้ตารางฉบับ พ.ศ. 2564 ที่บังคับใช้ขณะนั้น — ไม่ใช่ฉบับปัจจุบัน)
- โครงเอกสาร: ปร.4(ก) 17 แผ่น + ปร.5(ก) + ปร.5(ข) + ปร.6 + Factor F worked example

## 2) โครงสร้างกลุ่มงาน (ตามเอกสารจริง)
- **กลุ่มงานที่ 1** — 7 หมวด: โครงสร้าง / สถาปัตยกรรม / สุขาภิบาล / ไฟฟ้า / ... / ระบบพิเศษ
- **กลุ่มงานที่ 2** — ครุภัณฑ์สั่งทำ + งานตกแต่ง (ผ่าน Factor F)
- **กลุ่มงานที่ 3** — ภูมิทัศน์ + ผังบริเวณ
- ครุภัณฑ์**จัดซื้อ** ไม่อยู่ในกลุ่มงาน — เข้า ปร.5(ข) ×1.07 ไม่ผ่าน F

## 3) เลข baseline (Factor F + ยอดเงิน)
| รายการ | ค่า |
|---|---|
| Factor F interpolate ดิบ | 1.261173 |
| Factor F หลังปัด 4dp | **1.2612** |
| Direct Cost (ค่างานต้นทุน) | 14,489,053.08 |
| ยอดหลังคูณ F | 14,489,053.08 × 1.2612 = **18,273,593.74** |

**กติกาที่พิสูจน์:** interpolate → ปัด 4dp (`Math.round(f*10000)/10000`) → ค่อยคูณ
ตรงเอกสารทุกสตางค์ — ถ้าคูณด้วยค่าดิบไม่ปัด จะคลาด

## 4) กติกาปัดเลขที่ล็อกจากเอกสารชุดนี้
1. **qtyFinal ปร.4 = ปัดขึ้น (ceil) 2 ตำแหน่ง** — หลักฐานในเอกสาร: 5.42 ลบ.ม., 6.94 ตัน
   (จำนวนเต็มเป็นแนวกรมโยธาฯ 2544 เก่า — ยืนยันวิศวกร 10 มิ.ย. 2569: เอาตาม สพฐ. จนกว่ามีข้อมูลหักล้าง)
2. **Factor F = override ไม่ปัด** (เฉพาะค่าจาก interpolate เท่านั้นที่ปัด 4dp)
3. **เหล็กเสริม**: compute เก็บ กก. เต็ม precision เสมอ → แสดง**ตัน 3 ตำแหน่ง**ที่ชั้น export เท่านั้น
   (ห้าม ceil 2dp บนหน่วยตัน — เคยพิสูจน์คลาด 8 กก.)

## 5) ข้อสังเกต Factor F ข้ามปี
- เอกสารนี้ใช้ตารางฉบับ พ.ศ. 2564 → F = 1.2612
- ตารางปัจจุบัน = ว.499 (กค 0433.2/ว 499 ลว. 28 ส.ค. 2566, ดอกเบี้ยเงินกู้ 7% ต่อปี)
  เงื่อนไขเดียวกัน → interpolate 1.2960→1.2611 ที่ 14.489ล. = 1.264666 → 1.2647
- ตาราง ว.499 มี 4 ประเภทงาน (อาคาร/ทาง/สะพาน+ท่อเหลี่ยม/ชลประทาน) ประเภทละ 12 ตาราง
  Estimate-BOQ ใช้เฉพาะ **งานก่อสร้างอาคาร** — ในโค้ดคือ `src/data/factorF-CGD-2567.ts`
  (ชื่อไฟล์เรียกตามปีใช้งาน — ค่าทุกตัว verify ตรง PDF ว.499 แล้ว 11 มิ.ย. 2569)
- **ต่างกัน = พฤติกรรมถูกต้อง** ไม่ใช่ bug
- การ reproduce เอกสารเก่า: ส่ง F ของเอกสารเข้า por5Summary ตรง ๆ (override)
- งานใหม่: ใช้ตารางปัจจุบันผ่าน effectiveFactorF() เสมอ
