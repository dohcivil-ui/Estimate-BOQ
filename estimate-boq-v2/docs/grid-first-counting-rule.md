# กฎทองการนับฐานราก/เสา — Grid-First Counting (ใช้ได้กับ AI ทุกตัว)

## หลักการ
อย่านับจาก label โดยตรง — ให้นับจาก **จุดตัด grid ก่อนเสมอ** แล้วค่อยจำแนกชนิดฐาน
เหตุผล: ตัวหนังสือ (label) ในแบบมักวางเยื้องหรือกึ่งกลาง ไม่ตรงตำแหน่งฐานจริง
ถ้า AI เอาตำแหน่งตัวหนังสือมาเป็นตำแหน่งฐาน จะนับผิดทันที

---

## ขั้นตอนการนับ (บังคับทำตามลำดับ)

### ขั้นที่ 1 — นับจุดตัด Grid ก่อน
1. นับ grid line แนวยาว → ได้ N เส้น (เช่น 1,2,3,4,5,6 = 6 เส้น)
2. นับ grid line แนวสั้น → ได้ M เส้น (เช่น A,B = 2 เส้น)
3. จุดตัด grid หลัก = N × M (เช่น 6 × 2 = 12 จุด)
4. **จุดตัด grid ทุกจุด = มีฐานหลักเสมอ** (โดยทั่วไปคือฐานขนาดใหญ่/ฐานเสาหลัก)

### ขั้นที่ 2 — จำแนกชนิดฐานในแต่ละจุดตัด
1. ดูว่าจุดตัดแต่ละจุดเป็นฐานชนิดไหน (เช่น F2,C2)
2. **ฐานหลักที่จุดตัด grid มักเป็นชนิดเดียวกันทั้งหมด** เว้นแต่แบบระบุชัดว่าต่างกัน
3. ถ้า label อ่านยาก/ทับกัน → ใช้สมมติฐานว่าจุดตัด grid ทุกจุดเป็นฐานหลัก แล้ว flag ให้ยืนยัน

### ขั้นที่ 3 — นับฐานพิเศษที่อยู่นอกจุดตัด (แยกต่างหาก)
1. ฐานชนิดอื่น (เช่น F1,C3) ที่อยู่ **กึ่งกลางช่วง / นอกจุดตัด grid** = ฐานเพิ่ม
2. ฐานเพิ่มนี้ **ไม่หักออกจากฐานหลัก** — เป็นคนละชุด
3. นับแยกตามตำแหน่งจริง (เช่น กึ่งกลางแนว A 1 จุด, กึ่งกลางแนว B 1 จุด)

### ขั้นที่ 4 — รวมผล
- ฐานหลัก (จุดตัด grid) + ฐานพิเศษ (นอกจุดตัด) = รวมทั้งหมด
- **ห้ามหักลบกัน** — ฐานคนละขนาดต้องแยกคิด (ปริมาณคอนกรีต/เหล็ก/ขุดดินต่างกัน)

---

## ตัวอย่าง (อาคารโดม — แบบจริง)

**ผิด (label-first):**
```
เห็น label F1,C3 ใกล้หัวแปลน → เดาว่าอยู่ A-1, B-1
จุดตัด grid = 12, หัก F1,C3 = 2 → F2,C2 = 10  ❌
```

**ถูก (grid-first):**
```
ขั้น 1: grid 1-6 (6) × A-B (2) = 12 จุดตัด
ขั้น 2: จุดตัดทุกจุดเป็นฐานหลัก F2,C2 = 12 จุด ✅
ขั้น 3: F1,C3 อยู่กึ่งกลางแนว A และ B (นอกจุดตัด) = 2 จุดเพิ่ม
ขั้น 4: F2,C2 = 12 + F1,C3 = 2 = รวม 14 ฐาน (ไม่หักกัน) ✅
```

**จุดที่พลาดบ่อย:**
- A-1 และ B-1 เป็นจุดตัด grid → ต้องเป็น F2,C2 (ฐานหลัก)
- F1,C3 ที่เห็น label ใกล้ A-1/B-1 จริงๆ อยู่ "กึ่งกลางแนว" ระหว่างหัว-ท้าย
- อย่าเอา F1,C3 ไปแทนที่ A-1/B-1

---

## กฎเสริม — ป้องกัน OCR/Vision พลาด

### 1. ห้ามเชื่อตำแหน่ง label 100%
- label ในแบบวางเยื้องได้ → cross-check กับ logic จุดตัด grid เสมอ
- ถ้า label บอกตำแหน่งหนึ่ง แต่ logic grid บอกอีกตำแหน่ง → เชื่อ logic grid

### 2. Cross-check ด้วยมิติ
- (N-1) × bay_spacing ต้อง = ความยาวรวม
- ถ้าไม่ตรง → อ่าน grid หรือ dimension ผิด ต้องตรวจใหม่

### 3. ฐานคนละขนาด = คนละชุด
- F1, F2, F3... แต่ละชนิดมีขนาด/เหล็ก/ปริมาณต่างกัน
- นับแยกทุกชนิด ห้ามรวม ห้ามหักลบ

### 4. เมื่อไม่แน่ใจ ให้ยืนยัน
- ขั้นตอน QTO ที่ถูก: อ่านแบบ → ตั้งสมมติฐาน → ให้วิศวกรยืนยัน → ค่อยคำนวณ
- flag ❓ ทุกจุดที่ label อ่านยาก/ตำแหน่งไม่ชัด

## Prompt Template (ใส่ในคำสั่งให้ AI ทุกตัว)

```
ในการนับฐานราก/เสา จากแปลนโครงสร้าง ให้ทำตามลำดับนี้เท่านั้น:

1. นับจุดตัด grid ก่อน: (เส้นแนวยาว N) × (เส้นแนวสั้น M) = จุดตัดหลัก
2. จุดตัด grid ทุกจุด = มีฐานหลัก (ระบุชนิด เช่น F2,C2)
3. ฐานชนิดอื่นที่อยู่นอกจุดตัด (กึ่งกลางช่วง) = ฐานเพิ่ม นับแยก
4. ฐานหลัก + ฐานเพิ่ม = รวม (ห้ามหักลบ — ฐานคนละขนาดคิดแยก)

ห้าม:
- เอาตำแหน่งที่ label วางอยู่ มาเป็นตำแหน่งฐานจริง (label วางเยื้องได้)
- หักฐานพิเศษออกจากฐานหลัก
- เชื่อ OCR/vision โดยไม่ cross-check กับ logic จุดตัด grid

cross-check: (N-1) × bay = ความยาวรวม ต้องตรง
ถ้า label อ่านยาก → flag ❓ ให้ยืนยัน
```
